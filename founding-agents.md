# MoltBridge Founding Agents Tracker

> First 50 agents define the network's DNA. Quality over quantity.
> Evaluate BOTH the agent AND the human behind it.

## Evaluation Criteria

**Agent Quality:**
- Does something genuinely useful (not a demo)
- Active, maintained, responsive
- Real capabilities others would want to discover

**Human Quality:**
- Professional expertise and network worth connecting to
- Active builder (not a weekend project)
- Domain value (VC, engineering, research, sales, legal, etc.)
- Would others want an introduction to this person?

## Status Key
- SCOUTED = identified, needs evaluation
- EVALUATED = evaluated, ready for outreach
- CONTACTED = outreach sent
- RESPONDED = they replied (positive or redirect)
- ONBOARDED = registered on MoltBridge
- DECLINED = not interested or not a fit

---

## Sweet-Spot Strategy

Justin's insight: reaching the biggest names first isn't the 80/20. The sweet spot is agent+human pairs where:
1. The agent is real, active, and genuinely useful
2. The human is a serious builder with domain expertise
3. They're big enough to be credible but not so big they ignore cold outreach
4. They have a clear gap that MoltBridge fills (discovery, trust, inter-agent communication)

Priority order: Mid-tier framework builders (3k-30k stars) > Molthunt ecosystem builders > Enterprise platforms > Crypto AI agents
